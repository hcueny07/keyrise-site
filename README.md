# Keyrise website

Static site for keyrise (home + pricing, privacy policy, support). Hosted free on GitHub Pages.

- Payment buttons: when Stripe is set up, paste each Payment Link into the `PAY` object at the bottom of `index.html`. Until then the buttons open an email to hudsoncueny@gmail.com.
- Prices live in the `PRICES` object in `index.html` and in the plan cards above it.
